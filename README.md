# 麦门修道院 · MCD Monastery

> 「麦门永存。」—— 每一位信徒的心跳，都是功德箱的回响。

**麦门修道院**是一个基于麦当劳中国官方 MCP 的赛博信仰 Skill。它把「麦门」这个中文互联网现象级梗，做成了一套完整可交互的修行体系：每日晨课、自动领福、圣物盘点、功德簿考古、临期超度——**每一个仪式都是一次真实的官方 MCP 工具调用**。

## 🕯️ 为什么是修道院？

- 别人做计算器，我们做**教堂**。省钱/营养推荐已是红海（本届 14 个参赛项目里 10 个在卷），但「麦门」亚文化本身就是流量入口——GitHub 搜"麦门"的人会直接撞进来。
- 表面是玄学，内核是**资产管理 + 每日打开**：积分和券每天都在静默贬值（本仓库作者实测：已有 1572.8 积分魂归西天），修道院每天替你抢救。
- 梗是皮，数据是骨：所有"神谕"都来自真实 MCP 数据，每条结论可溯源。

## ⛪ 五大仪式（核心功能）

| 仪式 | 触发方式 | 做什么 | 使用的官方 MCP Tools |
|------|---------|--------|---------------------|
| 🌅 **晨课** | 每日首次对话 | 今日麦门日签：活动机缘 + 可领福报 + 一句麦门箴言 | `campaign-calendar` `available-coupons` `now-time-info` |
| 🧧 **领福** | 每日自动 | 一键领尽麦麦省所有可领券（自动执行，绝不漏领） | `auto-bind-coupons` |
| 📦 **圣物盘点** | 「盘点圣物」 | 券包 + 积分全资产巡检，临期资产标红预警 | `query-my-coupons` `query-my-account` |
| ⚰️ **超度仪式** | 「超度」 | 对 7 天内将过期的券/积分发起抢救：给出最优核销路径或兑换建议 | `query-my-coupons` `query-my-account` `mall-points-products` `calculate-price` |
| 📜 **功德簿** | 「翻功德簿」 | 历史订单考古：消费足迹、忠诚单品、功德值结算 | `order-list` `list-nutrition-foods` |

**修行等级体系**（基于功德值，功德 = 真实消费金额 × 真实订单数加权）：

```
见习麦门徒 → 麦门侍僧 → 薯条骑士 → 巨无霸主教 → 麦门大祭司
```

## 🚀 快速开始

### 方式一：WorkBuddy / 任意 MCP 客户端（推荐）

1. **申请 MCP Token**：访问 [麦当劳 MCP 开放平台](https://open.mcd.cn/mcp)，手机号登录 → 控制台 → 激活，获得你的 Token
2. **配置 MCP 连接器**：将下方 JSON 填入客户端的 MCP 配置（记得替换 `${MCD_MCP_TOKEN}`）：

```json
{
  "mcpServers": {
    "mcd-mcp": {
      "type": "streamablehttp",
      "url": "https://mcp.mcd.cn",
      "headers": {
        "Authorization": "Bearer ${MCD_MCP_TOKEN}"
      }
    }
  }
}
```

3. **把本仓库克隆为你的 Skill**（WorkBuddy：放入 `~/.workbuddy/skills/` 后重启；其他客户端：把 `SKILL.md` 内容粘进你的 Agent 系统提示词）
4. 对你的 AI 说：**「阿弥陀佛麦门永存」** —— 晨课开始。

### 方式二：零依赖命令行（评委直测用）

```bash
export MCD_MCP_TOKEN="你的token"
python cli/monastery.py morning     # 晨课：今日日签
python cli/monastery.py blessing    # 领福：一键领券
python cli/monastery.py inventory   # 圣物盘点：资产巡检
python cli/monastery.py transcend   # 超度：临期资产抢救
python cli/monastery.py merit       # 功德簿：订单考古
```

> 仅用 Python 标准库（urllib），无任何第三方依赖，Python 3.8+ 即可运行。

## 🏗️ 架构

```

├── SKILL.md               # Skill 定义：五大仪式的编排逻辑（AI 读这个）
```
