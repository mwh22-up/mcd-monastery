> 实测时间：2026-10-10 09:26 ~ 09:40（北京时间）
> 实测身份：真实麦当劳会员（MCP Token 绑定本人账号）
> 实测环境：Windows / Python 3.13.12（仅标准库）/ 直连 `https://mcp.mcd.cn`

本文档记录五大日课的完整真实运行输出，作为项目「真实使用麦当劳 MCP 能力」的可核验证据。

**本文所有输出块可由 `python cli/cathedral.py --demo <日课>` 原样复现**（输出基线存于 `tests/golden/`，由 `tests/test_align.py` 回归校验）。

## 实测一：数据探底（决定项目可行性的三个关键发现）

### 发现 1：套餐定制深度远超预期

`query-meal-detail`（猪柳蛋麦满分组合，上海黄浦华旭国际大厦餐厅）：

- **2 轮特调、35 个可选项**
- **87 个定制项、9 种定制类型**：吉士、奶油球、白砂糖、冰量（标准/去冰/少冰/多冰）、浓缩咖啡加量（不加/加）等
- 数据含 `selectedKey`/`unselectedKey` 传参规则，可直接进算价链路

→ 支撑「守夜日课」给出精确到"去冰多吉士"级别的核销路径。

### 发现 2：临期资产是真实且严重的问题

本账号实测（2026-10-10）：

- 券包 27 张在持，**12 张 7 天内过期**，其中：
  - 「巧克力味厚松饼猪柳蛋套餐」**当天过期**
  - 「人气麦旋风买一送一」**当天过期**
- 积分账户：**已熄灭 1572.8 分**（历史过期损失，无法追回）

→ 大教堂的核心痛点不是臆想，是每个麦门信徒都在真实流血的伤口。

### 发现 3：历史订单数据完整可考古

`order-list` 返回 10 笔订单全维度（时间/门店/金额/商品/子项），配 `list-nutrition-foods`（160 项营养库）可做热量结算。
